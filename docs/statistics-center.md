# 统计中心：运营总览与门店分析

## 页面定位

首页提供本月摘要与业务入口。统计中心围绕“当前服务规模、期间开展量、门店差异”组织内容，使用同一套运营统计接口和授权范围。总部与门店复用页面结构，不使用角色显示名称推断权限。

| 页面 | 业务问题 | 数据来源 | 范围与时间 |
| --- | --- | --- | --- |
| 运营总览 | 当前服务多少人，所选期间开展多少业务？ | operations/overview | 当前人数按当前归属；开展量按冻结门店、提交日/首次成功日 |
| 门店分析 | 授权门店之间有何差异，单店趋势如何？ | 同一份 overview 响应中的 stores、daily | 与总览共享日期、门店选择；表格搜索不改变汇总范围 |
| 数据说明 | 数据截至何时，为什么存在未知归属？ | 指标定义、overview 的发布时间与 unknown_reasons | 未发布或查询失败时仍可阅读定义；仅有效响应显示本次状态 |
| 总部专题 | 接入、医生、入口及计划执行表现如何？ | 原 overview、clinicians、entries 接口 | 保留既有权限与各专题口径，不自动套用门店筛选 |

## 操作与显示规则

- 总览默认本月，提供上月、近 7 个完整上海自然日、自定义日期。显示的结束日期包含当天，接口的 `to` 为次日零点，左闭右开。
- 当前服务人数不随所选历史日期变化；界面不能把当前值描述为历史快照。
- 总览显示最多五家门店的简表，按编号顺序，不代表绩效排名。门店分析提供完整列表、名称/编号搜索与指标排序。
- 单店“查看趋势”切换到门店分析并选择该店；日期保留。可恢复全部授权门店。
- 停用门店保留历史开展量，不从列表自动隐藏。
- 提交数包含独立问卷，完成数只计首次评估成功，两者不能相除展示完成率。
- 公司汇总包含未知开展量；仅指定门店的范围不显示公司未知桶。历史未知不得依据当前门店或医生补算。
- A 店开始、转 B 店后提交，开展量仍归 A 店；明细读取继续遵守现有权限和当前归属。

## 查询与失败边界

`OperationsPanel → useOperationsStatistics → operations/overview、operations/stores`。

- 概览与授权门店选项独立请求。选项失败时禁用范围选择并明确报错，已成功的指标仍展示。
- 切换总览、门店分析、数据说明不重新请求数据；改变日期、门店、刷新或身份/权限信息时请求对应数据。
- 数据按身份与筛选键绑定，旧请求迟到不能覆盖新范围；加载新范围时不展示旧范围计数。
- 授权门店选项不随“所选门店”重复加载；后端仍是权限和 Scope 的最终依据。
- 首页 compact 模式不请求完整门店选项，不显示门店对比表。
- 总部专题由独立入口按需挂载。医生与入口仅在打开相应专题时加载，各自错误独立显示，不能将请求失败呈现为空数据。
- 未发布、失败、已发布的零值分别表达，不为满足图表展示补零或生成模拟数据。
