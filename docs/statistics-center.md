# 统计中心：运营总览与门店分析

首页保留本月摘要与业务入口。统计中心统一为运营总览、门店分析、数据说明；不再提供独立总部专题入口，也不请求旧专业专题接口。

## 门店分析

| 页签 | 数据接口 | 口径 |
| --- | --- | --- |
| 服务概览 | operations/analysis/overview | 当前受试者归属下累计服务、期间接入与测评事件 |
| 临床人员 | operations/analysis/clinicians、entries | 当前门店医生，指标同时过滤受试者当前归属 |
| 计划执行 | 与服务概览共用一次 overview 请求 | 当前受试者范围内任务事件及版本化履约 |
| 历史开展 | operations/overview | 开始时冻结门店，提交量与首次成功量分开计数 |

四个页签共享日期与门店选择，默认本月及服务概览。结束日期在选择器中包含、在 API 中采用次日零点且不包含。总部可选全部、单店、多店；普通门店仅见授权选项。仅运营统计 read 权限允许本页面，不增加专业结果或任何管理操作入口。

## 分页、异步与边界

医生与入口默认20条、最多100条，由服务端在门店过滤后分页。医生总体卡片使用后端全范围 summary；当前页图表明确标注当前页，不以首10条推算总体。入口支持医生 ID、启用状态筛选，只展示内容标识与计数，不展示 Token 或扫码地址。

专题按需加载，服务与计划在相同筛选下复用响应。医生、入口错误和重试独立。身份、权限、日期、门店变化后旧结果立即不可见，迟到响应不得覆盖新范围。门店选项独立加载，失败禁用筛选并显示错误。未发布、覆盖不足、失败不能冒充零值。

当前归属读取时间、历史事件截止日期、发布版本分别显示。医生调店后原店不再列该医生，但留原店的受试者历史服务仍留原店；医生行合计不代表完整服务量，多医生关系也可能重叠。匿名入口打开不构成严格转化漏斗，不计算新转化率。计划履约沿用原分子、分母与零分母展示。

受试者转店后前三个专题跟随当前归属；历史开展保持原店。人工初配不用于回填历史开展。未知开展桶仅公司全部门店可见；未归属受试者不进入当前归属专题。两个提交/成功指标不能相除展示完成率。

## 发布与验收

本次更新 QS 安全专题接口及运营端；无需 IAM 授权变更、数据库迁移、采集端发布或全量统计重建。先发布 QS，再发布本页面。旧专业接口保持门禁和契约；回滚优先恢复上一运营端，不放宽后端权限。

自动化覆盖专题复用、分页与完整汇总、独立失败/重试、身份切换与乱序响应；保留现有日期、权限撤销、未知桶及数据说明测试。QS 同时验证真实 MySQL 的门店过滤、分页、医生调店及计划履约。

自动化、部署版本、总部和普通门店 API 正反场景、界面确认分别记录。历史验收答卷的次日计数核对仍是独立待验收项。
