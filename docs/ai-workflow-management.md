# qs-ai 配置与草稿管理入口

入口：`/operations/ai-governance/configuration`，沿用现有后台登录与组织管理员路由保护。此页通过 QS 的 `/internal/v2/interpretation/ai-workflow` 代理访问 qs-ai；组织及操作人由 QS 从认证上下文产生，浏览器不提交权限声明。

## 当前能力

- 查看 Profile、Prompt、模型路线、Schema 和评测套件的不可变版本目录，按精确标识查询、游标加载更多及读取正文。
- 从指定 Prompt 版本创建草稿，填写新模板标识、新版本及操作理由；打开已知草稿 UUID。
- 编辑系统说明、任务模板、数据前缀和允许变量，按当前修订号保存。未保存的修改不能冻结。
- 校验并冻结当前修订，显示冻结版本回执。冻结成功后当前编辑器只读；冻结不表示评测通过或生产发布。

目录代理要求 QS 资产目录版本（QS PR #98）及 AI AssetCatalog（AI PR #60）。草稿和冻结要求相应已部署接口。服务端治理开关关闭、授权拒绝或通信失败时显示不可读取，不能当作空目录。

## 结果未知与恢复

每次创建、保存、冻结都使用新命令 UUID；浏览器在发送前把原命令 UUID、草稿 UUID 和操作类型写入按当前账号分隔的 sessionStorage。记录不包含 Prompt 正文、操作理由或令牌。存储失败不发请求。

这些写请求使用 `internalV2PostOnce`，401 不自动刷新并重放。网络错误、超时、409 或不匹配的成功回执保留原命令并锁定新写入；用户只能查询原命令回执。回执暂时 404 不能证明原写入未生效。明确的 400/401/403/404/429 写请求拒绝可结束本次命令；服务端仍是最终幂等与授权边界。

页面重载会恢复待核对命令；正常成功后的草稿需自行保存 UUID 后重新打开。目前没有草稿目录，也没有未知命令人工处置入口。损坏的本地记录或持续缺失的回执需要管理员核对，不能以清空记录作为安全重试依据。重新打开草稿使用独立的 lifecycle 接口，核对明确状态、当前修订及冻结版本。未知状态、接口不可用或版本不一致不开放编辑；恢复旧创建/保存回执后也先读当前生命周期，读取失败继续保留原命令锁。冻结命令回执仍通过原查询恢复。

## 2026-09-13：原生策略版本注册

配置目录中的 Profile、Prompt 和模型路线详情可分别选择“用于注册策略版本”，在“解读策略”页签填写新版本及理由。复用策略的现有事实、输入、安全与质量规则，仅修改版本及明确选择的 Prompt/路线绑定；完整配置可展开核对。本页尚不提供任意策略规则编辑器。

注册通过 QS 的 `POST /profiles/register`，查询原命令通过 `GET /profiles/commands/{command_id}`。成功时核对原命令、配置内容与五项不可变版本引用，显示策略、Prompt 和路线版本，阻止当前已注册版本再次提交。注册成功不等于评测通过或发布；套件绑定、评测、审核与发布仍是后续步骤。

每个账号的 sessionStorage 仅保留待确认注册命令 UUID，不保存策略正文、理由或凭据。发送前写入失败则不发送；超时、409 或回执不匹配保留原命令并锁定写入；刷新后查询原回执，暂时 404 不释放锁。接口沿用不自动重放的写请求通道。

本批 5 个相关测试套件、22 项测试通过，覆盖策略规则保留、目录选择、版本引用、重复点击、原回执恢复、账号隔离及存储失败；TypeScript、全库 ESLint 和生产构建通过。隔离 React 预览使用合成 API 验证中文表单、注册成功摘要和同版本提交禁用，未连接生产 QS/IAM，不构成真实管理或 M1–M3 业务验收。
