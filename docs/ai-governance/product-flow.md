# AI 解读管理：方案工作流

第一版以现有发布契约为基础，把普通操作从资产目录移至方案首页。

## 本版已实现

- 进入页面读取通用量表范围的真实发布状态；读取失败不显示为已停用，不推断用户准入开关。
- 从线上方案继承精确 Prompt、策略、生成模型和语义模型版本，校验资产指纹；完整案例来源沿用现有套件注册契约。
- 冻结 Prompt 后，通过一个准备动作注册新策略并绑定完整测试套件，不调用模型、不发布。继续复用现有命令回执和未知结果保护。
- 五步流程指引和下一步说明；实际发布成功仅由匹配本轮评测的服务端发布记录确认。
- 首页直接选择已有测试；最终拒绝后可从该轮配置创建修改版本，保留失败与审核记录。
- 候选正文按实际展示结构阅读；批量审核用表格选择、角色、意见完成，不要求 JSON。签名仍需实际审核者确认。
- 高级资产目录仍可访问，旧接口不重新启用。

## 使用路径

方案首页 → 从线上方案创建修改版本 → 填写理由并创建草稿 → 编辑/保存 → 冻结 → 继续准备测试 → 填写准备理由并确认 → 查看计划/创建/启动 → 阅读候选/人工审核 → 最终审核 → 核对并发布。

准备阶段不产生模型费用；启动评测仍要求确认调用预算。当前草稿需显式保存，未实现自动保存。

## 验证和边界

自动化覆盖资产错配/读取失败、策略保留、回执后顺序绑定且不重复、跨步骤语义路线继承、账号切换以及非 JSON 批量审核签名门槛。保留原治理测试。自动测试不代替浏览器及实际管理员验收。

这版未增加后端接口。任意模型参数编辑、多方案首页、跨刷新完整编辑会话恢复、冻结输入事实与正文的完整左右对照仍需要后续工作；现有响应主要提供候选执行证据，不能用线上最新报告冒充冻结输入。模型路线可在高级目录选择已有版本，当前常规路径继承来源模型。

草稿、策略和套件是不同服务端对象；自动绑定不是原子事务。失败时按原命令回执恢复，不自动生成另一个版本或绕过冲突。刷新后现有各工作区仍通过其原恢复入口处理待确认命令；完整方案级恢复属于后续项。

尚未以本版执行生产评测、人工签名或切换发布。当前 v6 不受代码开发影响。
